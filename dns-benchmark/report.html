04

Geschwindigkeit zuhause selbst messen

Speed muss auf deiner Leitung gemessen werden. Dieses Skript braucht nur Python 3 (auf macOS/Linux vorinstalliert, Windows: python.org) — keine Installation. Es misst alle Anbieter über viele Runden, erkennt sogar, ob dein Router DNS umleitet, und gibt eine sortierte Tabelle aus.

Terminal · dns_speed_test.py
# 1) Skript aus dem Repo laden (dns-benchmark/dns_speed_test.py)
# 2) ausführen — fertig:
python3 dns_speed_test.py

# mehr Runden für stabilere Werte, eigenen Router mittesten:
python3 dns_speed_test.py --rounds 15 --extra 192.168.1.1=Router

# Ergebnis: sortierte Tabelle (min/median/p95/Verlust) + CSV + JSON

Was in Mitteleuropa typisch ist

Cloudflare, Google & Quad9 betreiben Knoten in Frankfurt/Amsterdam/Zürich — meist < 20 ms. Kleinere Anbieter (Level3, Comodo) sind oft langsamer/schwankender. Verifiziere es mit dem Tool.

Worauf es ankommt

Nicht der Bestwert zählt, sondern Median + p95 + Ausfallrate: ein Resolver, der selten, aber stark ausreißt, bremst das Surfen spürbarer als ein konstant guter.
